# 💜 Flash Wash ⚡️ — V3.1

نظام محاسبة وإدارة مخصص لشركة فلاش لغسل السيارات.

## الموجود
- تسجيل دخول آمن بكلمات مرور مشفرة، مع تحديد عدد المحاولات الفاشلة
- حسابان إداريان مبدئيان: حسن وحيدر
- لوحة تحكم يومية بتوقيت بغداد
- طلبات بأنواعها: عادي، مميز، حمام، بوليش، مع تغيير حالة الطلب من الجدول
- سيارات: ناصية وعالية
- كباتن: عباس، أيمن، فهد، سيف
- عملاء وسجل غسلات
- اشتراكات شهرية مع تسجيل الغسلات المستخدمة
- مصروفات وتقارير حسب الكابتن والخدمة
- سجل تدقيق لكل حركة
- مستخدمون وصلاحيات، مع ربط حساب الكابتن باسمه وإمكانية إيقاف الحساب
- نسخة احتياطية كاملة بصيغة

JSON

## الصلاحيات
- المدير: كل شيء
- الكابتن: يضيف طلبات باسمه، ويرى طلباته فقط، ويغيّر حالتها فقط، ولا يرى المصروفات أو التقارير أو الإيرادات

## البنية
الخادم:

Node.js 20+ / Express

قاعدة البيانات:

PostgreSQL (Neon)

الاستضافة:

Render (Frankfurt)

الجداول تُنشأ تلقائياً عند أول تشغيل، ولا حاجة لتشغيل أي أوامر يدوية على قاعدة البيانات.

## متغيرات البيئة
انظر الملف:

.env.example

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط قاعدة البيانات من Neon |
| `JWT_SECRET` | سر توقيع الجلسات، إلزامي في الإنتاج |
| `INITIAL_ADMIN_PASSWORD` | كلمة المرور الأولى للمديرين، تُستخدم مرة واحدة فقط عند أول تشغيل |
| `APP_TZ` | المنطقة الزمنية، الافتراضي بغداد |

إذا لم تُحدَّد كلمة المرور الأولى فسيولّد النظام كلمة عشوائية ويطبعها في سجل الخادم مرة واحدة.

## التشغيل المحلي
```bash
npm install
cp .env.example .env   # ثم عدّل القيم
node --env-file=.env server.js
```
ثم افتح:

http://localhost:3000

## النشر الحالي
العنوان:

https://flashwash.onrender.com

الخدمة مُنشأة يدوياً في رندر داخل مشروع «فلاش وش»، بمنطقة فرانكفورت، وتُنشر تلقائياً مع كل دمج في الفرع الرئيسي. متغيرات البيئة المضبوطة عليها:

DATABASE_URL, JWT_SECRET, NODE_ENV=production, APP_TZ=Asia/Baghdad, NODE_VERSION=22

مسار فحص الصحة:

/healthz

قاعدة البيانات في نيون بمنطقة:

eu-central-1

## إعادة الإنشاء من الصفر
الملف التالي يصف الخدمة نفسها، ويمكن استخدامه لإنشائها من جديد عند الحاجة:

render.yaml

1. أنشئ مشروعاً في نيون بمنطقة فرانكفورت وانسخ رابط الاتصال المجمّع
2. في رندر اختر:

   New → Blueprint

   واربط هذا المستودع
3. أدخل رابط القاعدة، وكلمة المرور الأولى إن كانت القاعدة فارغة
4. بعد اكتمال النشر سجّل الدخول وغيّر كلمات المرور
